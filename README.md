Car Rental System

A full-stack car rental application that allows users to browse available cars, view car details, and book rental vehicles.

Tech Stack:
Frontend: React.js, Vite
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT
Image Storage: ImageKit
Features:
User registration and login
Browse and search cars
View car details
Car booking and rental management
User profile
Smart car recommendations
Admin car management
